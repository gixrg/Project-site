2. General Methodology

A comprehensive overview of our step-by-step approach to identifying, auditing, and solving semantic gaps using formal ontologies and Large Language Models.

Phase I

Knowledge Graph Auditing

We interrogate the ArCo SPARQL endpoint to assess the density of metadata linked to Sandro Botticelli's *La Primavera*. By running progressive query patterns, we test whether individual internal actors are structured as semantic nodes or left unindexed.

Tools: SPARQL, ArCo Endpoint Mining
Phase II

Advanced Prompt Engineering

We deploy specific prompting strategies (Zero-Shot System Constraints, Few-Shot Structural Alignment, and Chain-of-Thought Spatial Extraction) across multiple foundational models to extract tabular and spatial metadata without chat commentary.

Models: GPT-4o, Claude 3.5 Sonnet, Llama 3
Phase III

Ontological Mapping & Reconciliation

We translate the unstructured text outputs into standard W3C RDF triples. Individual characters are re-modeled as active components using the official ArCo ontology framework and reconciled with external knowledge sources via Wikidata alignments.

Standards: RDF, Turtle, Wikidata URI Linking
