2. General Methodology

A structured multi-tiered framework leveraging Semantic Web standards and Large Language Models for automated knowledge extraction.

Phase I

Knowledge Graph Auditing

Programmatic interrogation of the official ArCo SPARQL endpoint to assess metadata granularity. This phase formalizes data omissions regarding the internal narrative components of targeted artworks, establishing a baseline for the semantic gap.

Constructs: SPARQL, Registry Mining, Validation
Phase II

LLM Prompt Engineering

Design and evaluation of advanced prompting paradigms across foundational models. By enforcing precise ontological bounds and spatial processing rules, the system orchestrates zero-shot, few-shot, and chain-of-thought operations to process visual information.

Paradigms: Zero-Shot, Few-Shot, Chain-of-Thought
Phase III

Ontological Mapping & Fusion

Transformation of flat model outputs into fully compliant RDF/Turtle data structures. The extracted components are mapped to the ArCo schema, cross-referenced with Wikidata external URIs, and synthesized into the reconciled global graph.

Standards: W3C RDF, Turtle, ArCo Ontology Alignment

Methodological Pipeline Architecture

The core architectural innovation relies on using Large Language Models not as simple text generators, but as specialized Knowledge Engineering components capable of structural alignment. The process follows a strict validation cycle:

// 1. Data Harvesting & Constraint Setup

The pipeline initializes by extracting existing records from institutional graphs. The extracted fragments are evaluated to build the strict system boundary configurations passed to the inference models.

// 2. Controlled RDF Extraction & Ingestion

LLMs process the unstructured artistic records under structural constraints. The generated syntax is parsed, validated against the ArCo vocabulary specification, and linked to open authority data records.
