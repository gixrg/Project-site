Technique 1: Zero-Shot System Constraints
Isolate the core characters into independent component nodes. Strip out all aesthetic interpretations. Output only valid Turtle syntax using the ArCo framework.
// Target Input Prompt (Sent to LLMs)
Act as a Semantic Web Knowledge Engineer. Analyze Sandro Botticelli's artwork "La Primavera" to resolve its internal characters. You must follow these strict operational constraints:

1. Isolate every single one of the 9 core characters into a dedicated node modeled explicitly as an instance of the class a-cd:CulturalPropertyComponent.
2. Link each component back to the parent artwork URI (ex:Primavera_Artwork) using the object property core:hasPart.
3. Assign an rdfs:label string to each component containing their primary mythological identification (Zephyrus, Chloris, Flora, Venus, Cupid, Aglaia, Euphrosyne, Thalia, Mercury).
4. Output ONLY a valid W3C Turtle file using the prefixes: ex:, a-cd:, core:, and rdfs:. Do not include any conversational preamble, markdown explanations, or chat commentary.
