2. Incremental SPARQL Auditing Engine

To methodologically isolate and expose this informational void, our team designed a three-step query strategy, concluding with a comprehensive query integrating **all 7 mandatory modifiers**: DISTINCT, UNION, OPTIONAL, FILTER, REGEX, ORDER BY, and LIMIT.

Tappa C: Definitive Gap Analysis Query (All 7 Modifiers)

PREFIX arco: <https://w3id.org/arco/ontology/arco/>
PREFIX a-cd: <https://w3id.org/arco/ontology/context-description/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT DISTINCT ?artwork ?title ?subject
WHERE {
    { ?artwork a arco:HistoricOrArtisticProperty . }
    UNION
    { ?artwork a arco:CulturalProperty . }
    
    ?artwork rdfs:label ?title .
    
    FILTER(?artwork = <https://w3id.org/arco/resource/HistoricOrArtisticProperty/0900158550>)
    FILTER(lang(?title) = "it")
    
    OPTIONAL { ?artwork a-cd:hasSubject ?subject . }
}
ORDER BY ?title
LIMIT 10
