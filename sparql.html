3. SPARQL Query Auditing Engine

Our semantic audit was conducted using a progressive pipeline to verify the data depth of the ArCo Knowledge Graph and mathematically isolate the targeted gap.

ACT I

Discovery: Searching for "Primavera"

The first step addresses Entity Discovery within a national-level aggregation graph. We execute a broad semantic lookup targeting instances of the core class arco:HistoricOrArtisticProperty. We apply a case-insensitive regular expression filter (FILTER(REGEX(..., "i"))) on the rdfs:label property to evaluate whether the token "Primavera" is present as a literal string. 

SELECT DISTINCT ?culturalProperty ?label
WHERE {
  ?culturalProperty a arco:HistoricOrArtisticProperty .
  ?culturalProperty rdfs:label ?label .
  FILTER(REGEX(?label, "Primavera", "i"))
}

ACT II

Attribution: Isolating Botticelli's Masterpiece

To achieve precise Entity Resolution, we introduce a structured graph join. We exploit the object property a-cd:hasAuthor to bridge the artwork node directly to its creator entity, restricting the scope with a secondary filter targeting "Botticelli". 

SELECT DISTINCT ?culturalProperty ?label ?authorLabel
WHERE {
  ?culturalProperty a arco:HistoricOrArtisticProperty .
  ?culturalProperty rdfs:label ?label .
  ?culturalProperty a-cd:hasAuthor ?author .
  ?author rdfs:label ?authorLabel .
  
  FILTER(REGEX(?label, "Primavera", "i"))
  FILTER(REGEX(?authorLabel, "Botticelli", "i"))
}

ACT III

The Global Subject Scan (The Illusory Overlap)

Before pinning the target canvas, we ran a global subject query using a-cd:hasSubject on any artwork labeled "Primavera". This intermediate step highlights a common challenge in data validation: names of independent characters (like Cupid or Mercury) appear in the output stream, but they belong to miscellaneous regional assets or different frescoes, not to Botticelli's canvas. 

SELECT DISTINCT ?subjectLabel
WHERE {
  ?culturalProperty rdfs:label ?label .
  FILTER(REGEX(?label, "Primavera", "i"))
  
  ?culturalProperty a-cd:hasSubject ?subjectNode .
  ?subjectNode rdfs:label ?subjectLabel .
}

ACT IV

Chirurgical Audit: Isolating Botticelli's Subject Gap

This final query represents the Definitive Content Audit. By forcing a strict conjunctive condition that matches "Primavera" and "Botticelli" simultaneously, we extract the precise iconographical boundaries of the Uffizi masterpiece.

If the characters were structurally indexed as semantic graph components, the output would display individual nodes for each iconographical component. Instead, it exposes the complete absence of granular modeling. 

PREFIX arco: <https://w3id.org/arco/ontology/arco/>
PREFIX core: <https://w3id.org/arco/ontology/core/>
PREFIX a-cd: <https://w3id.org/arco/ontology/context-description/>
PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>

SELECT DISTINCT ?culturalProperty ?label ?authorLabel ?subjectLabel
WHERE {
  ?culturalProperty a arco:HistoricOrArtisticProperty .
  ?culturalProperty rdfs:label ?label .
  FILTER(REGEX(?label, "Primavera", "i"))
  
  ?culturalProperty a-cd:hasAuthor ?author .
  ?author rdfs:label ?authorLabel .
  FILTER(REGEX(?authorLabel, "Botticelli", "i"))
  
  OPTIONAL {
    ?culturalProperty a-cd:hasSubject ?subjectNode .
    ?subjectNode rdfs:label ?subjectLabel .
  }
}
ORDER BY DESC(?culturalProperty)
